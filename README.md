# HELLOTRIGRE

Plataforma web/PWA demonstrativa de entretenimento.

## Importante
Este repositório implementa somente uma experiência de demonstração com pontos fictícios, sem valor monetário. Não há apostas reais, depósitos, saques, pagamentos ou conversão de pontos em dinheiro.

## Tecnologias
- React + TypeScript
- Vite
- Lucide icons
- PWA manifest

## Executar localmente
```bash
npm install
npm run dev
```
